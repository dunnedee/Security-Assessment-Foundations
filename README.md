# Foundations of Security Assessments

An open, free learning resource for people getting into penetration testing and
security assessment. The content is organised around the CREST CPSA syllabus and
written as defensive reference material, what each concept is, why it matters,
how an assessor identifies the related weakness, and how it's remediated.

**check out the Live site:** https://dunnedee.github.io/Security-Assessment-Foundations/


## Or Run it locally

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000.

## Contributing

Spotted an error or want to suggest an addition? Open an issue or pull request.
Please keep contributions in the same defensive, conceptual register (concept →
how it's assessed → remediation), and don't contribute exam-specific or recalled
content.
