# Host & platform security

Beyond the network lies the configuration of the hosts and platforms on it — how
identity is managed, how files are protected, and how infrastructure devices are
set up. These are where a great many real findings live, because they come down
to settings, permissions, and defaults.

- **[Active Directory](active-directory.md)** — the identity backbone of Windows
  environments, and why it's such a high-value target.
- **[File system security](file-system-security.md)** — permissions, encryption,
  and how data at rest is protected.
- **[Device configuration review](configuration-analysis.md)** — reading the
  settings of infrastructure devices to find security weaknesses.

!!! tip "The recurring theme"
    Almost everything in this section reduces to **least privilege, no defaults,
    and good hygiene.** Hold that lens and the specifics fall into place.
