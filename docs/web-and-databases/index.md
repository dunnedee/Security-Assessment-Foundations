# Web & databases

Web applications are among the most tested systems in the industry, because
they're exposed to the world and they handle valuable data. This section covers
the common classes of web weakness and the security of the databases behind
them — framed, as always, around cause, identification, and fix.

- **[Common web vulnerabilities](web-vulnerabilities.md)** — the recurring
  weakness classes and the single root cause behind most of them.
- **[Database security](databases.md)** — how the data layer is protected.

!!! info "One idea to carry through"
    Most web vulnerabilities come down to one thing: **trusting input that
    should never be trusted.** Hold onto that and the specific weaknesses become
    variations on a theme rather than a list to memorise.
