# Foundations of Security Assessment

A free, open learning resource for people getting into **penetration testing
and security assessment**. The material is organised around the
**CREST CPSA** syllabus and written as plain-English reference material: what
each concept is, why it matters, how an assessor looks for the related
weakness, and how organisations fix it.

It is aimed at newcomers — career-changers, IT professionals moving into
security, and anyone building the foundational knowledge the industry expects
before you ever touch a live target.

!!! note "What this is — and isn't"
    This is **study and reference material mapped to the public syllabus**. It
    is written from a **defensive, assessment-oriented** point of view and
    contains **no exam questions, recalled content, or step-by-step attack
    recipes**. The goal is understanding, not a copy-paste playbook.

## How to read each page

Most pages follow the same shape so you can learn the pattern once:

1. **The concept** — what it is, in plain terms.
2. **Why it matters** — the real-world security relevance.
3. **How it shows up in an assessment** — what a tester looks for, at a
   conceptual level.
4. **Remediation** — how organisations prevent or fix it.
5. **Check your understanding** — a few open questions to test yourself. These
   are study prompts, not exam questions.
