# Reference

Quick-reference tables to look things up and to revise from. These are
deliberately terse — the explanation lives in the topic sections; this is the
cheat-sheet layer.

- **[Protocols & acronyms](protocols-acronyms.md)** — common networking and
  security protocols, what they're for, and secure-versus-insecure pairings.
- **[Common ports](common-ports.md)** — the ports worth knowing, their services,
  and port-security notes.

!!! tip "Learn the secure/insecure pairs"
    When revising protocols and ports, the highest-value thing to internalise is
    the **pairs**: Telnet vs SSH, FTP vs SFTP, HTTP vs HTTPS, LDAP vs LDAPS,
    SNMPv2 vs SNMPv3. Knowing which is which — and that the secure one should be
    preferred — covers a lot of ground.
